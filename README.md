# Dompetku - Praktikum PAB Pertemuan 7

Aplikasi Flutter untuk materi List, TabBar, dan Gambar.

## Cara menjalankan
1. Ekstrak folder project.
2. Buka folder `Dompetku_Prak7` di VS Code.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter run -d chrome`.

## Fitur
- Tab Transaksi menggunakan `ListView.builder`.
- Tab Kategori menggunakan `GridView.builder` dengan dua kolom.
- Tab Profil menggunakan `Image.network` dan `AssetImage`.
- Tab Statistik mengurutkan pengeluaran dari nominal terbesar.
- Form tambah transaksi dengan validasi.
- Kategori Kesehatan dengan gambar lokal.

Catatan: folder `assets/images` sudah berisi gambar PNG sederhana buatan untuk praktikum.
